With the touch controls on, the game uses its own default control style 1.1 (HONEY). Aiming can be set to toggle instead of hold in the watch's Control options. Picture at the top when the phone is upright, controls on the sides when it is turned.
Save
Your progress and settings are stored only in this browser, for this ROM (IndexedDB). Clearing the site's data deletes them, and other browsers or devices do not see them: export the save to keep a copy or to move it. Import accepts a 2048-byte GoldenEye EEPROM file (this page's export, the PC port's ge007.eep, or an emulator's .eep); the game restarts with it.
